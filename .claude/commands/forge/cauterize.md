> _Iolaus the Cauterizer prevents unbounded regeneration._ One cauterization per chain — Reflexion ×1 — but the memory of past burns lives in TheEights. The reflexion-coach will pull prior critiques on the same stage from the project's history when composing the retry prompt.

Run `/pp:retry $ARGUMENTS`. The behavior is identical to `/pp:retry`; the alias exists to name the act mythically. The cross-run reflexion lookup is automatic when the reflexion-coach is given `stage_kind` and `project_path` (which the driver already supplies). Read `.claude/commands/pp/retry.md` for the canonical contract.
