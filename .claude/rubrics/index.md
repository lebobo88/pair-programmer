# Rubric registry (mirror)

The canonical source for these rubrics is `daemon/src/rubrics/registry.ts`. The markdown files in this directory are mirrors generated by `node dist/index.js dump-rubrics` (run from `daemon/`, with the project-root `.claude/rubrics` dir passed explicitly) so the daemon ships self-contained while humans can still read/copy them. Drop a customized rubric at `<project>/.claude/rubrics/<bare-id>.md` to override one for a specific project (loaded via `daemon/src/rubrics/loader.ts`) — this also works for entirely new ids not yet in the registry, since the loader falls back to disk for any unmatched id.

Operations:
- Inspect a rubric body at runtime: `mcp__pp_harness__get_rubric` with the id.
- List all rubrics: `mcp__pp_harness__list_rubrics`.
- Regenerate these mirrors after editing `registry.ts`: from `daemon/`, run `node dist/index.js dump-rubrics ../.claude/rubrics` (the bare `dump-rubrics` with no target dir writes relative to the current working directory, not the project root — always pass the target dir explicitly). This command does not touch `index.md`; update this file by hand when rubrics are added/removed.
